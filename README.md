# OfficeHQ Study Cases

Repository lưu trữ kiến thức và study case của dự án OfficeHQ, dùng chung cho Claude và Codex.

## Bắt đầu

- Codex đọc [AGENTS.md](AGENTS.md).
- Claude đọc [CLAUDE.md](CLAUDE.md).
- Study case nằm trong [study-cases](study-cases/README.md).
- Skill của Codex đặt tại `.agents/skills/<ten-skill>/SKILL.md`.
- Skill và subagent của Claude đặt tại `.claude/skills/<ten-skill>/SKILL.md` và `.claude/agents/<ten-agent>.md`.
- Agent tùy chỉnh của Codex đặt tại `.codex/agents/<ten-agent>.toml`.
- Trang tài liệu công khai dùng Docusaurus nằm trong [publics](publics/README.md).

Hiện đây là bộ khung. Nội dung và quy ước chi tiết sẽ được bổ sung sau.
